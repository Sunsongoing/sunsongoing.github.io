# sunsongoing.github.io

GitHub Pages 个人主页

## 生成方式

本项目使用 [Hexo](https://hexo.io/) 静态博客框架 + [Melody](https://github.com/Molunerfinn/hexo-theme-melody) 主题生成。

## 文件结构

```
.
├── css/           # 样式文件
├── js/            # JavaScript 文件
├── img/           # 图片资源
├── tags/          # 标签页
├── index.html     # 首页
├── favicon.ico    # 网站图标
└── README.md      # 本文件
```

## 如需重新生成

1. 安装 [Node.js](https://nodejs.org/)
2. 安装 Hexo CLI: `npm install -g hexo-cli`
3. 初始化 Hexo 项目并配置 Melody 主题
4. 运行 `hexo generate` 生成静态文件
5. 将 `public/` 目录内容推送到 GitHub
